★ La règle d'or : toujours ranger le résultat

La plupart des méthodes fabriquent un nouveau tableau sans toucher à df. Sans df =, le résultat s'affiche… puis disparaît.

Vrai aussi pour drop_duplicates, fillna, drop, rename, merge… Seules df["col"] = … et df.loc[…] = … modifient directement le tableau.

Rien trouvé. Essaie un autre mot : « vide », « double », « colonne », « type », « date »…
